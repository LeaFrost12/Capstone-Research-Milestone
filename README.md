# CSCE 490 Research Milestone

A small, local Next.js application for previewing a personal credit-card wallet. This checkpoint uses temporary mock data only; no accounts or cards are saved.

## Requirements

- Node.js 20.9 or later
- npm

## Run locally

1. Install packages: `npm install`
2. Start the development server: `npm run dev`
3. Open [http://localhost:3000](http://localhost:3000).

## Checks

Run `npm run lint` and `npm run build`.

## Current scope

This checkpoint includes a responsive static wallet, mock card data, an add-card form, and client-side validation. It deliberately does not include Clerk, Supabase, Prisma, Vercel, authentication, or persistent storage.
